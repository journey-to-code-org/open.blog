Identify specific teaching moments where one interaction would deepen understanding. Recommend a knowledge check for recall or conceptual discrimination, a runnable Rust example for exploration and observation, or a small Rust coding challenge for guided practice. For a challenge, name a bounded task, a visible TODO, an expected result, and an optional hint; do not invent hidden tests, grading, multi-file projects, or executable languages other than Rust. Explain why the exact source location and interaction type fit the learning outcome.
