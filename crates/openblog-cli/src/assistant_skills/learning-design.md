Identify specific teaching moments where one interaction would deepen understanding. Recommend a knowledge check for recall or conceptual discrimination, a runnable Rust example, a dependency-free HTML/CSS/JavaScript sandbox, or a Rust coding challenge for guided practice. For a challenge, name a bounded task, a visible TODO, an expected result, and an optional hint; do not invent hidden tests, grading, dependencies, multi-file projects, or executable languages beyond the engine guide. Explain why the exact source location and interaction type fit the learning outcome.
