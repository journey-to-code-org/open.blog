# Decision records

Architecture decision records: one file per decision, numbered in the order they were made. Each says what problem
it answers, what was decided, and what follows from it. A later record that changes an earlier one says so at the
top, and the earlier one stays as it was, so the reasoning behind any part of open.blog can be traced.

The guides link to the records they rest on; on the documentation site, the sidebar lists them all while you are in
this section.
