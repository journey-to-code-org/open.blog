A tutorial sticks when the reader can try it. The parts of this series show every interactive
lesson block open.blog has: runnable Rust, Rust challenges graded by hidden tests, HTML, CSS and
JavaScript sandboxes, and simulated labs for Git, networking, web components and more.

Every block falls back to plain, readable code for readers without JavaScript, in feeds, and in
copies you syndicate elsewhere, so no lesson is lost when it cannot run.
