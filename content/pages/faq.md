---

Short answers. [The documentation's FAQ](https://journey-to-code-org.github.io/open.blog/docs/faq/) has more.

```piece faq
question: Do I need a database or a server?
answer: No. The site is plain files that any static host can serve. Studio is a small
  program you run when you want to edit in the browser. [Deploying](https://journey-to-code-org.github.io/open.blog/docs/deploy/) lists hosts.
question: Do I have to write Markdown?
answer: No. [Studio](/studio/) has a visual editor and an **Add something** menu. It writes
  Markdown files, so you can open them in any editor later.
question: Can it be more than a blog?
answer: Yes. Pages, a front page you arrange, recipes, services, lessons and a documentation
  section all come from the same folder. See [Kinds of sites](/sites/).
question: Are my readers tracked?
answer: No. View counts, comments and share links are built in, with no cookies and no
  third-party scripts. See [Views, comments and sharing](/posts/views-comments-and-sharing/).
question: What does it cost?
answer: Nothing. open.blog is free software under the GPL, version 3 or later. The
  [source is on GitHub](https://github.com/journey-to-code-org/open.blog).
question: What if I want to leave?
answer: Your posts are Markdown files in a folder you own. Copy the folder.
question: Where do I ask for help or report a problem?
answer: Open an issue on [GitHub](https://github.com/journey-to-code-org/open.blog/issues).
```
