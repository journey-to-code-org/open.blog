[open.blog](https://github.com/journey-to-code-org/open.blog) is a blogging engine that turns a folder of Markdown files into a fast,
static website. It comes with [Studio](/studio/), a browser editor for people who would rather
not touch the files.

This site is built with it. Every post is a working example of a feature, with the
instructions to use it on your own site, and the pages show how a site can be more than a list
of posts.

## What makes it different

- **Your words stay yours.** Posts are plain text files in a folder you own. There is no
  database to back up and nothing to export.
- **Readers are not tracked.** View counts, comments and share links are built in, with no
  cookies and no third-party scripts.
- **It is not only for code, and not only a blog.** Recipes, trade jobs, field journals,
  research and lessons each get the fields they need, beside pages, a front page and a
  documentation section. See [Kinds of sites](/sites/).
- **It works everywhere.** Any static host can serve the site. Feeds, search and interactive
  lessons still work, in a plainer form, when JavaScript is off.
