This handbook is part of open.blog's example site. Each page is a Markdown file in
`content/docs/`, and the sidebar, the **Previous** and **Next** links and the search box come
with it. [Documentation beside your blog](/posts/documentation-beside-your-blog/)
explains how it is set up.

Start with [Getting started](getting-started.md), then read [the guides](guides/index.md).
